# C# Engineering Labs

A collection of focused, runnable **.NET 8** mini-projects covering data structures, validation and practical application logic.

## Mini-projects

| Project | Problem | Skills |
| --- | --- | --- |
| [Inventory Tracker](./projects/inventory-tracker/) | Prevent inconsistent inventory changes | Encapsulation, input validation, stock transactions |
| [Sliding Window Rate Limiter](./projects/rate-limiter/) | Control request bursts | Data structures, time windows, boundary testing |

## Run

Install the **.NET 8 SDK**, then execute the examples and tests without external dependencies:

```bash
dotnet run --project projects/inventory-tracker
dotnet run --project projects/rate-limiter
dotnet run --project tests/EngineeringLabs.Tests.csproj
```

The solutions are educational samples newly published in 2026. No artificial historical commit dates.
